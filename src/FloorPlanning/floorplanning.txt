FloorPlanning UI Tool Usage Tips:

###########
### RUN ###
###########
- run Aurora UI
- make sure at least two stages are completed (SYNTHESIS and PACKING)
- navigate to the menu "View" where "IP Configurator" and "Pin Planner" are located and run third item "Floorplanning"

################################
### PARTITIONS LIST CONTROLS ###
################################
- Double Left Mouse Button Click - enter to partition renaming

############################
### DEVICE GRID CONTROLS ###
############################
Mouse:
- Holding [Left Button] + dragging on empty area — draw a Region for the currently selected Partition.
- Holding [Left Button] + dragging on corner of Region — resize the Region.
- Holding [Left Button] + dragging on center of Region — move the Region.
- Click [Left Button] on one of the Regions — select the whole Partition the clicked Region belongs to.
- Click [Left Button] on red button of the Region — delete Region.
Note: when a Partition is selected, it is highlighted in blue.
- Holding [Right Button] + dragging — change the device grid viewport position.
- Scroll wheel — zoom in / zoom out.

Keyboard:
- [UP], [LEFT], [RIGHT], [DOWN] — change the device grid viewport position.
- Keyboard button [DELETE] — remove the currently selected Partition.
- Keyboard button [ESC] — unselect the currently selected Partition.

###################
### LIMITATIONS ###
###################
1) Currently, the PACKING run stage is required to build the netlist for the FloorPlanning UI.
2) Aurora crash scenario https://github.com/QL-Proprietary/aurora2/issues/1614
Workaround to avoid it:
Whenever you use Save QDC, make sure that the VPR View (if used) is closed before the save QDC event.
